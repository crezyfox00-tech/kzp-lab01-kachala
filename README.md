# Лабораторна робота № 6
## «Обробка даних засобами Python»

Репозиторій містить рішення лабораторної роботи № 6 для Варіанта 12 (**«Розсадник рослин»**). Проєкт реалізовано у вигляді модульного Python-пакету з підтримкою тестування, лінтингу, збирання у `wheel`-пакет та автоматизації CI/CD.

---

## 📋 Основні характеристики
* **Варіант:** 12 (Розсадник рослин).
* **Предметна область:** Облік параметрів рослин (`species`, `age`, `height`, `price`, `watering_days`).
* **Мова програмування:** Python 3.11+.
* **Інструменти якості та збирання:** `pytest`, `ruff`, `build`.

## ⚙️ Встановлення та запуск

### 1. Клонування репозиторію та створення віртуального середовища
python -m venv .venv
.venv\Scripts\activate

### 2. Встановлення пакету в режимі розробника (з інструментами тестування)
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"

### 3. Запуск модульних тестів (pytest)
python -m pytest

### 4. Перевірка якості коду та форматування (ruff)
ruff check .
ruff format --check

### 5. Запуск програми через командний рядок (CLI)
python -m kzp_lab06.cli data\input.csv reports\plant_summary.txt

### 6. Збирання дистрибутиву (wheel)
python -m build

## 📊 Алгоритм аналізу (Варіант 12)
1. **Фільтрація:** відбір рослин із періодичністю поливу `watering_days <= 2`.
2. **Агрегування:** розрахунок середньої ціни за кожним видом рослин у детермінованому порядку.
3. **Пошук:** визначення найвищої рослини серед відібраної вибірки.
4. **Звітування:** збереження результатів у структурованому текстовому форматі в кодуванні `UTF-8`.
