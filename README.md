# Лабораторна робота № 2 — Класи, record і інкапсуляція (Варіант 12)

## Призначення
Програма читає записи про рослини розсадника з файла `data/input.csv`, перетворює їх на незмінні об'єкти класу-сутності `Plant`, обчислює статистичні показники варіанта 12 за допомогою допоміжних `record` (`HeightWatering`, `PlantSummary`) і формує звіт у консоль та файл `out/report.txt`.

## Архітектура та класи
* `Main` — точка входу, яка лише ініціалізує парсер аргументів та запускає контролер.
* `CliOptions` — `record`-парсер аргументів командного рядка (`--help`, `--version`, `--input`, `--output`) та читання версії з `pom.xml` через ресурси.
* `NurseryController` — контролер, що керує читанням файлів, створенням списку сутностей та формуванням звіту.
* `Plant` — незмінний клас-сутність із `private final` полями, перевіркою інваріантів у конструкторі, статичним фабричним методом `fromCsv` та перевизначеним `toString()`.
* `HeightWatering` та `PlantSummary` — незмінні `record` для допоміжної пари значень (висота й інтервал поливу) та підсумкових показників звіту.

## Правила валідації (інваріанти `Plant`)
Формат рядка CSV (`UTF-8`, роздільник `;`):
`species:String; name:String; heightCm:double; price:double; wateringDays:int`

* `species` та `name` — не `null` і не порожні після `trim()`.
* `heightCm` — скінченне додатне число (`> 0`).
* `price` — скінченне невід'ємне число (`>= 0`).
* `wateringDays` — додатне ціле число (`> 0`).
