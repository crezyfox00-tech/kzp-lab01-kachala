# Лабораторна робота № 7
## «Об'єктно-орієнтована обробка даних у Python»

Репозиторій містить рішення лабораторної роботи № 7 для Варіанта 12 (**«Розсадник рослин»**). Проєкт реалізовано у вигляді модульного об'єктно-орієнтованого Python-пакету з інкапсульованим станом, валідацією через властивості (`@property`), поліморфізмом на основі протоколів (`Protocol`), незмінними структурами (`dataclass`), підтримкою тестування, лінтингу, збирання у `wheel`-пакет та автоматизації CI/CD.

---

## 📋 Основні характеристики
- **Варіант:** 12 (Розсадник рослин).
- **Предметна область:** Об'єктна модель обліку рослин (`Plant: Tree, Flower`, спільний протокол `Cared`, розрахунок `care_score`).
- **Мова програмування:** Python 3.11+.
- **Інструменти якості та збирання:** `pytest`, `ruff`, `build`.

## ⚙️ Встановлення та запуск

### 1. Клонування репозиторію та створення віртуального середовища
python -m venv .venv
.venv\Scripts\activate

### 2. Встановлення пакету в режимі розробника (з інструментами тестування)
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"

### 3. Запуск модульних тестів (pytest)
python -m pytest -o pythonpath=src

### 4. Перевірка якості коду та форматування (ruff)
ruff check .
ruff format --check

### 5. Запуск програми через командний рядок (CLI)
python -m kzp_lab07.cli data\input.csv reports\plant_summary.txt

### 6. Збирання дистрибутиву (wheel)
python -m build --wheel

## 📊 Алгоритм аналізу (Варіант 12, ООП)
1. **Завантаження та мапінг:** читання CSV та створення об'єктів підтипів `Tree` або `Flower` на основі даних із валідацією інваріантів через `@property` і setter.
2. **Фільтрація:** відбір рослин із періодичністю поливу `watering_days <= 2`.
3. **Агрегування:** розрахунок середньої ціни за кожним видом рослин у детермінованому порядку та поліморфний розрахунок оцінки догляду (`care_score`).
4. **Пошук:** визначення найвищої рослини серед відібраної вибірки через незмінний датаклас підсумку `PlantSummary` (`frozen=True`).
5. **Звітування:** збереження результатів у структурованому текстовому форматі в кодуванні `UTF-8`.
