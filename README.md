## Опис проєкту
Проєкт реалізує рефакторинг попередньої предметної моделі розсадника рослин шляхом переходу від класичних циклових обчислень до декларативних запитів **Stream API**. Усі операції відбору, перетворення, групування, статистики та впорядкування винесено в окремий клас `NurseryReport`, що забезпечує чистоту коду, відсутність побічних ефектів і повну зворотної сумісність.

---

## Архітектура та реалізовані запити
У класі **`NurseryReport`** реалізовано п'ять обов'язкових запитів Stream API та безпечний пошук через `Optional`:
1. **Фільтр (`filter`):** Відбір рослин із періодичністю поливу не більшою за 2 дні.
2. **Перетворення (`map`):** Отримання відсортованого списку всіх видів рослин.
3. **Групування (`groupingBy`):** Обчислення середньої ціни за категоріями (`PlantKind`) із використанням `EnumMap`.
4. **Статистика (`summarizingDouble`):** Зведена статистика за висотою рослин (`DoubleSummaryStatistics`).
5. **Топ-N (`sorted` + `limit`):** Вибір топ-5 рослин за допомогою складеного компаратора (основний критерій — висота за спаданням, додатковий — вид за зростанням).
6. **Пошук (`Optional`):** Безпечний пошук рослини за її видом (`findBySpecies`), що виключає появу `null`.
