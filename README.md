## 🚀 Етапи реалізації наскрізного проєкту

### Лабораторна робота № 3: Поліморфна ієрархія класів та юніт-тестування
* **Суть роботи:** Спроєктовано та реалізовано поліморфну ієрархію класів предметної області «Розсадник рослин» із використанням абстрактного базового класу `Plant`, підтипів `Tree` та `Flower`, а також перерахування `PlantKind`.
* **Особливості:** Забезпечено суворий контроль інваріантів у конструкторах, реалізовано коректні контракти `equals`, `hashCode` та `toString`, покрите модульними тестами JUnit 5 та перевірене статичним аналізатором SpotBugs.

### Лабораторна робота № 4: Потокова обробка даних (Stream API)
* **Суть роботи:** Виконано глибокий рефакторинг обчислювальної логіки. Класичні цикли обходу колекцій замінено на декларативні конвеєри Stream API (`filter`, `map`, `groupingBy`, `summarizingDouble`, `sorted`, `limit`).
* **Особливості:** Додано складні компаратори (`Comparator.comparingDouble().thenComparing()`), безпечний пошук через `Optional`, а також зведену статистику числових параметрів рослин без порушення початкової поведінки програми.

### Лабораторна робота № 5: Параметризоване сховище, винятки й CSV-експорт
* **Суть роботи:** Завершено наскрізний цикл збереження даних. Пряме збереження у списку замінено на узагальнене сховище `Repository<T>`, додано рефлексивний механізм експорту через власну анотацію `@CsvColumn`, документний парсер та повну обробку винятків.
* **Основні компоненти:**
  * **`Repository<T>`:** Типобезпечне сховище в пам'яті без `raw types` із підтримкою знімків `all()` та предикатного пошуку `find()`.
  * **`@CsvColumn`:** Власна анотація з `@Retention(RUNTIME)` та `@Target(FIELD)` для маркування експортованих полів.
  * **`CsvExporter` та `CsvParser`:** Універсальний рефлексивний експортер і документний розбірник, що коректно екранує коми, лапки та багаторядкові поля, запитуючи та читаючи дані через `Path`, `Files` із явним кодуванням `StandardCharsets.UTF_8`].
  * **`DataStorageException`:** Власний виняток предметної області із збереженням першопричини (`cause`), що запобігає «тихому» поглинанню помилок.
  * **Round-trip тести:** Комплексне модульне тестування, яке доводить повну ідентичність початкових та відновлених із CSV об'єктів для варіанта 12 (`PlantRecord`, ключ: `species + ageYears`).
