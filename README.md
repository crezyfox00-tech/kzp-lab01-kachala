Лабораторна робота № 1 — Розсадник рослин (Варіант 12)
Призначення
Консольна програма читає записи про рослини розсадника з файла data/input.csv, перевіряє коректність кожного рядка, обчислює статистичні показники варіанта 12 та формує звіт у консоль і текстовий файл out/report.txt.
Формат входу
Вхідний файл кодується у форматі UTF-8. Кожен рядок містить один запис, де 5 полів розділені крапкою з комою (;): species:String; name:String; heightCm:double; price:double; wateringDays:int
- species — вид рослини (непорожній рядок)
- name — назва рослини (непорожній рядок)
- heightCm — висота рослини в сантиметрах (додатне дробове число з крапкою)
- price — ціна в гривнях (невід'ємне дробове число з крапкою)
- wateringDays — інтервал поливу в днях (додатне ціле число)
Приклад вхідних даних (data/input.csv)
Хвойні;Туя західна Смарагд;120.5;450.00;7
Листяні;Клен гостролистий;210.0;850.50;5
Кімнатні;Фікус Бенджаміна;65.0;320.00;3

## Показники варіанта
1. Кількість коректних записів.
2. Середня висота рослин.
3. Найдорожча рослина.
4. Найменший інтервал поливу.
