* **Предметна область:** Розсадник рослин

---

## Опис проєкту
Проєкт реалізує ієрархію класів для розсадника рослин на основі принципу поліморфізму. У ході лабораторної роботи було створено абстрактний базовий клас `Plant` та конкретні підтипи `Tree` (дерево) та `Flower` (квітка). Програма забезпечує зчитування даних із CSV-файлів, валідацію вхідних даних, розрахунок показників догляду та формування сумісних звітів, зберігаючи повну зворотну сумісність із попередніми лабораторними роботами.

---

## Архітектура та структура
* **`Plant`**: Абстрактний базовий клас, що містить спільні поля (`species`, `name`, `kind`, `heightCm`, `price`, `wateringDays`) та абстрактний метод `careRequirement()`.
* **`Tree`**: Конкретний підтип для дерев із додатковим параметром діаметра стовбура (`trunkDiameterCm`).
* **`Flower`**: Конкретний підтип для квітів із додатковим параметром періоду цвітіння (`bloomingMonths`).
* **`PlantKind`**: Перерахування (`enum`) категорій рослин.
* **`NurseryController`**: Контролер для обробки колекцій та побудови звіту.
