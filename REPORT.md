## 2. Мета роботи
Досягнуто стану повноцінного модульного Python-застосунку для завантаження, валідації та аналізу даних розсадника рослин із CSV-файлу, побудови детермінованих звітів, автоматизованого тестування (`pytest`), контролю якості (`ruff`), збирання у `wheel`-пакет та налаштування CI/CD на базі GitHub Actions.

---

## 3. Формат CSV
* **Заголовок:** `species,age,height,price,watering_days`
* **Типи полів:**
  * `species` (рядок) — назва виду рослини.
  * `age` (ціле число, `int`) — вік у роках.
  * `height` (число з плаваючою комою, `float`) — висота у см.
  * `price` (число з плаваючою комою, `float`) — ціна у грн.
  * `watering_days` (ціле число, `int`) — періодичність поливу в днях.
* **Приклад екранованого рядка:** `"Сакура, декоративна",3,150.0,1250.0,2`
* **Правило порожнього входу:** Якщо файл містить лише заголовок або порожній, повертається порожній список записів, а звіт фіксує 0 відібраних елементів без виникнення винятків.

## 4. Структура модулів (`src/kzp_lab06/`)
* `errors.py` — визначення власного винятку `DataError`.
* `loader.py` — читання CSV через `csv.DictReader`, перевірка заголовків та валідація типів рядків.
* `analysis.py` — бізнес-логіка фільтрації (`watering_days <= 2`), розрахунок середньої ціни за видами та пошук найвищої рослини.
* `reporting.py` — детерміноване форматування результатів у текстовий звіт.
* `cli.py` — точка входу командного рядка (`argparse`) для зв'язування компонентів.

---

## 5. Перетворення даних
Використання списків (`list`), словників (`dict`), множин (`set`) та спискових включень (`list comprehensions`) для фільтрації та агрегування параметрів рослин із повним контролем числових діапазонів.

---

## 6. Функції
* Застосування типових параметрів, змінних аргументів `*args` (для додаткових числових метрик) та іменованих аргументів `**kwargs` (для кастомних назв міток у звіті) у функції `make_summary`.
* **Приклад виклику:** `make_summary(records, "price", price="Сумарна ціна")`.

---

## 7. Алгоритм аналізу
* **Відбір:** Фільтрація записів за критерієм `watering_days <= 2`.
* **Агрегування:** Обчислення середньої ціни для кожного унікального виду рослин.
* **Унікальні значення:** Формування множини видів (`species_set`) та сортування результатів для забезпечення стовідсоткової детермінованості виводу.

---

## 8. Обробка помилок
* Використання винятку `DataError`, який спадкується від `ValueError`.
* Формування інформативних повідомлень із зазначенням номера рядка (`Рядок N:...`).
* Ланцюжкова обробка винятків через `raise ... from error` та повернення коду виходу `2` у CLI у разі помилки.

## 10. Тестування (`pytest`)
* Позитивні тести перевіряють коректність розрахунку середньої ціни та підсумків.
* Крайові тести перевіряють роботу зі звітами через `tmp_path`.
* Негативні тести перевіряють реакцію на некоректні дані та порожній вхід.

## 11. Якість та пакетування
* Конфігурація лінтера та форматувальника у `pyproject.toml` (`ruff`).
* **Команди встановлення й запуску:**
  ```powershell
  .venv\Scripts\python.exe -m pip install -e ".[dev]"
  .venv\Scripts\python.exe -m pytest
  .venv\Scripts\ruff.exe check .
  .venv\Scripts\ruff.exe format --check
  .venv\Scripts\python.exe -m build
  ```
