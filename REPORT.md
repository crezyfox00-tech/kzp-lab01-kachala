## 1. Мета роботи

Метою лабораторної роботи є створення консольного Java-проєкту з використанням Maven, реалізація базової обробки даних із CSV-файлу, перевірка коректності вхідних даних, написання модульних тестів, виконання статичного аналізу та налаштування автоматичної перевірки проєкту за допомогою GitHub Actions.

## 2. Постановка задачі

Необхідно реалізувати консольну програму для обробки даних розсадника рослин.

Для кожної рослини використовуються такі поля:

- `species` — вид рослини (`String`);
- `name` — назва рослини (`String`);
- `heightCm` — висота у сантиметрах (`double`);
- `price` — ціна у гривнях (`double`);
- `wateringDays` — інтервал поливу у днях (`int`).

Програма повинна:

1. прочитати дані з CSV-файлу;
2. перевірити коректність кожного запису;
3. не завершувати роботу через некоректний рядок;
4. визначити кількість коректних записів;
5. обчислити середню висоту рослин;
6. визначити найдорожчу рослину;
7. визначити найменший інтервал поливу;
8. сформувати звіт у текстовому файлі;
9. підтримувати параметри командного рядка `--help`, `--version`, `--input` та `--output`.

У тестових даних використано як коректні, так і некоректні записи, а також українські символи.

4 Інфраструктура проєкту
Для складання проєкту використовується Maven.

У pom.xml налаштовано:

Java 21;

UTF-8;

JUnit 5;

Maven Wrapper;

SpotBugs для статичного аналізу;

Maven Shade Plugin для створення виконуваного JAR-файлу.

Для запуску Maven у Windows використовується Maven Wrapper:

PowerShell

Перевірка всього проєкту:

PowerShell

Створення JAR:

PowerShell

Після виконання package створюється виконуваний файл:

Plaintext
target/lab01-1.0.0.jar
Також налаштовано GitHub Actions. CI виконує перевірку проєкту на:

Ubuntu;

Windows;

macOS.

Для всіх операційних систем використовується Java 21 та команда verify. Після успішної перевірки JAR-файли зберігаються як CI artifacts.
