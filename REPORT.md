# ЗВІТ ПРО ВИКОНАНУ РОБОТУ (Лабораторна робота № 4)

### 1. Тема, номер і варіант
* **Тема:** Потокова обробка даних у Java-проєкті (Stream API).
* **Номер роботи:** Лабораторна робота № 4.
* **Варіант:** Варіант 12.
* **Предметна область:** Розсадник рослин.
* **Операційна система:** Windows (PowerShell, Maven).

### 2. Мета роботи
Замінити основні циклові обчислення в наявній предметній моделі розсадника на декларативні запити Stream API, не змінюючи зовнішню поведінку програми. Домогтися відбору, перетворення, групування, зведеної статистики, складеного впорядкування та безпечного пошуку через Optional.

### 3. Стан до і після цієї роботи
* **До роботи:** Дані оброблялися за допомогою класичних циклів (`for`/`while`) з ручною перевіркою умов, накопиченням проміжних результатів та розгалуженнями.
* **Після роботи:** Цикли замінено на декларативні конвеєри Stream API (`filter`, `map`, `groupingBy`, `summarizingDouble`, `sorted`, `limit`), що підвищило читабельність коду та відокремило логіку фільтрації й агрегації від виводу.

### 4. Контракт даних
* **Поліморфний тип:** Абстрактний базовий клас `Plant` із підтипами `Tree` та `Flower`.
* **Поля:** `species` (вид), `name` (назва), `kind` (`PlantKind` enum), `heightCm` (висота), `price` (ціна), `wateringDays` (періодичність поливу).
* **Правила валідності:** Назва та вид не можуть бути порожніми; числові параметри повинні бути додатними.

### 5. П'ять запитів
1. **Фільтр (`filter`):** Вибірка рослин із періодичністю поливу не більшою за 2 дні.
2. **Перетворення (`map`):** Отримання відсортованого списку всіх видів рослин.
3. **Групування (`groupingBy`):** Обчислення середньої ціни за категоріями (`PlantKind`).
4. **Статистика (`summarizingDouble`):** Зведена статистика за висотою рослин (кількість, мінімум, максимум, сума, середнє).
5. **Топ-N (`sorted` + `limit`):** Вибір топ-5 рослин за допомогою складеного компаратора (основний критерій — висота за спаданням, додатковий — вид за зростанням) та обмеження результату.

### 6. Групування та статистика
* **Групування:** Використовується `Collectors.groupingBy` у поєднанні з `EnumMap` для забезпечення стабільного порядку категорій та `Collectors.averagingDouble` для розрахунку середньої ціни.
* **Статистика:** Об'єкт `DoubleSummaryStatistics` безпечно опрацьовує як наповнені колекції, так і порожній вхід (повертаючи нульові показники та нескінченності для меж), що гарантує відсутність `NullPointerException`.
* **Форматування:** Числові значення форматуються з використанням `Locale.ROOT`.

### 7. Компаратор
* Складений компаратор побудований через `Comparator.comparingDouble(Plant::getHeightCm).reversed().thenComparing(Plant::getSpecies)`. 
* Виклик `reversed()` застосовується виключно до чисельного критерію висоти до додавання зв'язуючого критерію `thenComparing`, що гарантує правильне сортування (спочатку найвищі, а за рівності висоти — за абеткою видів).

### 8. Optional
* Пошук рослини за видом реалізовано через метод `findBySpecies`, який повертає `Optional<Plant>`.
* Використання `findFirst()` гарантує повернення першого знайденого елемента, а метод `.isEmpty()` дозволяє безпечно опрацювати відсутність результату без використання `null`.

### 9. Еквівалентність
| Запит / Операція | Циклова реалізація (до) | Потокова реалізація (Stream API) | Результат |
| :--- | :--- | :--- | :--- |
| **Фільтр поливу** | `for` + `if (p.getWateringDays() <= 2)` | `stream().filter(...).toList()` | Еквівалентний |
| **Види рослин** | `for` + ручний збір у `List` | `stream().map(...).sorted().toList()` | Еквівалентний |
| **Групування цін** | `for` + мапа і `putIfAbsent` | `stream().collect(groupingBy(...))` | Еквівалентний |
| **Статистика висоти** | `for` + ручний підрахунок `min/max/sum` | `stream().collect(summarizingDouble(...))` | Еквівалентний |
| **Топ-N рослин** | Сортування колекції + обрізка циклом | `stream().sorted(comp).limit(n).toList()` | Еквівалентний |
